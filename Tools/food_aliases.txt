# Синонимы для поиска по каталогу.
#
# Каталог знает русское и английское название, а дневник ведут на том языке, на
# котором написано на упаковке. У израильского товара с каталогом не совпадает
# ни одно слово: «אבקת חלבון» — это сывороточный протеин, «חלב» — молоко, и
# найти их было нельзя ни поиском, ни подбором донора витаминов.
#
# Формат: английское_название|синоним,синоним,...
# Английское название — ключ, тот же, что в food_core_usda.tsv. Синонимы в
# каталог попадают в поле «a» и работают в поиске, но человеку не показываются:
# на экране остаётся название на его языке.
#
# Иврит здесь без огласовок и в единственном числе там, где это естественно:
# поиск сравнивает нормализованные строки, а приставки и предлоги отбрасывать
# всё равно нечем.
