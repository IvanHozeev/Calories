# Рецепты готовых блюд каталога — ради витаминов, а не ради калорий.
#
# У блюда вроде борща нет строки в USDA: там есть капуста, свёкла и говядина
# по отдельности. Поэтому тридцать блюд каталога жили с макросами и без единого
# витамина, и день, собранный из домашней еды, показывал низкое покрытие,
# хотя ел человек ровно то, про что каталог всё знает.
#
# Состав считается по этим рецептам из продуктов того же каталога. Выводить
# витамины без рецепта нельзя: это было бы не оценкой, а выдумыванием чисел.
#
# ФОРМАТ. Одна строка на блюдо:
#     Название|Ингредиент:граммы|Ингредиент:граммы|...
#
# Граммы — НА СТО ГРАММ ГОТОВОГО БЛЮДА, а не на кастрюлю. У супа это значит,
# что большую часть занимает вода, и её надо написать явно: «Вода» — обычный
# продукт каталога, она честно весит и честно не содержит ничего. Без неё
# покрытие блюда считалось бы по одной гуще и завышало бы витамины втрое.
#
# Названия ингредиентов — русские, ровно как в food_core.txt.
#
# Сумма граммов должна выходить около ста, а посчитанные по рецепту калории —
# около тех, что стоят у блюда в food_core.txt. И то и другое проверяет
# build_food_catalog.py --check: разошлось — значит рецепт описывает не то
# блюдо, и витамины из него будут не те.
