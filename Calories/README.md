# Calories

Дневник питания и тела для iOS: калории, макросы и микронутриенты, вес и замеры,
план похудения/набора, пост и кашрут. SwiftUI + SwiftData, без сторонних
зависимостей.

- **Платформа:** iOS 26.0+
- **Bundle ID:** `ivankhozeyev.team.Calories`
- **Языки интерфейса:** русский, английский, испанский, португальский,
  французский, немецкий, арабский, иврит (включая RTL)
- **Проект:** `Calories.xcodeproj`, схема `Calories`

## Как запустить

1. Открыть `Calories.xcodeproj` в Xcode 26 или новее.
2. Выбрать схему `Calories` и симулятор с iOS 26+.
3. Запустить.

Внешних пакетов нет — проект собирается сразу после клонирования.

## Что умеет

### Дневник

- Кольцо калорий и карточки макросов на «Сегодня», список приёмов пищи.
- Добавление еды: встроенная база, свои продукты и блюда, ручной ввод,
  быстрые калории, штрихкод, распознавание блюда по фотографии.
- Состав приёма хранится по компонентам, поэтому «Недавнее», копирование
  и разбор дня знают, из чего собрана запись.
- Порции в граммах, пересчёт БЖУ, вес после готовки, парные продукты
  (например, мясо + молочное — для кашрута).
- История по дням, недельный график, разбор дня по макросам и
  микронутриентам, стрики.

### Тело и прогресс

- Вес: журнал взвешиваний, тренд, сравнение с калориями за тот же период.
- Замеры обхватов и их динамика, состав тела.
- Профиль: BMR по Миффлину-Сан Жеору, TDEE, активность, цель, норма белка.
- Адаптивный TDEE: расход уточняется по фактическому дневнику и весу.
- Сон, пульс покоя и шаги из HealthKit.

### План

- Целевой вес и срок, расчёт дневной нормы через дефицит/профицит.
- Адаптивная сверка: ожидаемый вес против фактического тренда, статус
  «по графику / опережаешь / отстаёшь», пересчёт нормы и сдвиг срока.
- Фазы дефицита с брейками (4:1), недельный цикл калорий с рефидом
  на выходных.
- Снапшоты исторических целей: прошлые дни не меняются задним числом.
- Итог недели и разбор застоя.

### Пост и кашрут

- Полные дни голодания, отметка начала/конца, подсказки до и после.
- Ожидание между мясным и молочным, настраиваемые интервалы,
  Live Activity с обратным отсчётом на экране блокировки.

### Вокруг приложения

- Виджеты: калории, макросы, шаги, ближайший приём пищи.
- Live Activity кошерного ожидания.
- Контролы Пункта управления и Siri: добавить еду, снять фото, штрихкод,
  замеры.
- Напоминания о приёмах пищи и взвешивании.
- Резервная копия в выбранную папку (в том числе iCloud Drive) и экспорт
  данных файлом.
- Локальная диагностика падений: разбор прошлого запуска прямо в настройках.

## Устройство

```
Calories/            приложение
  Core/              точка входа, корневые экраны, Siri/контролы, общий стор
  Model/             SwiftData-модели, CalorieStore и расчёты
  View/              экраны
  View/Components/   переиспользуемые компоненты
  Resources/         FoodCatalog.json, Nunito
Shared/              палитра и типы, общие с виджетами
CaloriesWidget/      виджеты, Live Activity, контролы
CaloriesTests/       юнит-тесты
CaloriesUITests/     UI-тесты
Tools/               сборка каталога еды, проверка переводов, прогон тестов
```

- **`CalorieStore`** — единственный источник состояния поверх `ModelContext`.
  Держит кэши дней, целей, трендов и трофеев; на нём же расчёты плана,
  адаптивного TDEE, кашрута и микронутриентов. Разнесён по расширениям
  `CalorieStore+Food/+Goals/+Kosher/+Micronutrients`.
- **SwiftData** — записи еды, вес, замеры, дни голодания, снапшоты целей.
  Профиль, план и флаги покупок живут в `UserDefaults`.
- **App Group `group.calories.shared`** — общие данные для виджетов,
  Live Activity и контролов.
- **`Shared/Palette.swift`** — цвета макросов и акцентов, одинаковые
  в приложении и расширениях.

## Питание и данные

Встроенная база — `Resources/FoodCatalog.json`, около трёхсот продуктов
с макро- и микронутриентами. Исходник — `Tools/food_core.txt`; после правки
каталог пересобирается:

```bash
python3 Tools/build_food_catalog.py --usda <путь к выгрузке USDA> --core-only
python3 Tools/build_food_catalog.py --check
```

Внешние источники:

- **Open Food Facts** — поиск и штрихкоды, без ключа.
- **USDA FoodData Central** — предпочтительный поиск, когда в отладочной
  сборке задан ключ; даёт витамины и минералы.
- **Gemini** — распознавание блюда по фотографии, ключ тоже задаётся
  в отладочных настройках.

Ключи не хранятся в репозитории: они лежат в `UserDefaults` устройства.
Синхронизации между устройствами нет; от потери телефона защищает резервная
копия в выбранную папку.

## Тесты

```bash
Tools/test.sh          # юнит-тесты, 10–20 секунд
Tools/test.sh --all    # вместе с UI-тестами, 8–12 минут
```

Скрипт сам находит симулятор, проверяет версию рантайма и чистит настройки
шрифта от прошлых прогонов. Тот же скрипт запускается в CI и в pre-push-хуке:

```bash
ln -sf ../../Tools/pre-push .git/hooks/pre-push
```

CI (`.github/workflows/tests.yml`) срабатывает на pull request в `main`
и по кнопке — macOS-минуты в приватном репозитории дорогие.

Перед правкой интерфейса стоит заглянуть в `.claude/skills/`: там конвенции
экранов и рабочий цикл проекта — тесты, переводы, оформление коммита.
